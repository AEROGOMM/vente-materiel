Stocké de façon centralisée sur Airtable — accessible depuis n'importe quel appareil. Limite : 5 Mo par fichier.

Paramètres

Nécessite une clé API Anthropic (console.anthropic.com) et une table Airtable dédiée (même base) avec les champs Article (texte) et Taux (nombre, ex. 0.05 pour 5%). La première fois qu'un article est lu dans un PDF, l'outil vous demande le taux à appliquer puis s'en souvient pour toujours. Le champ DateAnalysePdf (type Date) sur la table principale enregistre automatiquement la date de chaque analyse réussie.

Utilisez le même Token et le même Base ID que vos autres outils (même compte Airtable), avec une table dédiée. Champs requis dans cette table (respecter la casse) :

Entreprise, Interlocuteur, Telephone, Email, Adresse, Commercial, Statut (sélection unique — voir liste ci-dessous), MaterielConcerne, Fournisseur, Valorisation (nombre), DatePrevisionnelle (date), DateDemo (date), DateMiseEnRoute (date), DateCommande (date), MontantCommission (nombre), CommissionPayee (case à cocher), DateCommission (date), ProchaineRelance (date), CreneauRelance (sélection unique), Notes (texte long), DateCreation (type Created time).

Le champ PiecesJointes (type Pièce jointe / Attachment) permet de joindre devis, fichiers Excel ou photos directement depuis le formulaire (5 Mo max par fichier).

Valeurs exactes du champ Statut : Prise de contact, Suivi dossier, Démo programmée, Démo réalisée, Attente devis usine, Attente réponse Devis, Achat imminent, Matériel vendu, Commission due, Commission payée, Sans suite.

Valeurs exactes du champ CreneauRelance : Début de matinée, Fin de matinée, Début d'après-midi, Fin d'après-midi, Début de soirée.
